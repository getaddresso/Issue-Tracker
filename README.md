# Issue Tracker ✨

Welcome to our **Issue Tracker**! Here, you can submit **bugs, feature requests, and general feedback** – we'll review everything and track it in our internal workflow!
Every contribution helps **make things better for everyone**. Thanks for being part of the journey! 💜 

## 📝 How to Submit an Issue

1. **Click on "New Issue"**  
2. Choose the right issue type (Bug Report, Feature Request, or Other).  
3. Fill in the details:  
   - Clear **title**  
   - **Description** of the issue
   - Steps to **reproduce** (if applicable)  
   - **Screenshots** (if helpful)  
4. **Assign a label** (e.g., `bug`, `feature`, `enhancement`) to keep things tidy
5. Hit **"Submit new issue"** – we’ll take care of the rest!   

## What Happens Next?
- Your issue **syncs automatically** to our **Linear board**
- We'll review and categorize it based on priority.  
- If we need more info, we’ll drop a comment.

## Guidelines for a Smooth Flow
✔ Be as clear and concise as possible.  
✔ Check if a similar issue exists before submitting.  
✔ Assign a label (`bug`, `feature`, `enhancement`, etc.) to help us categorize it.  

Thanks for helping us improve!
